## 功能介绍

### 剪贴板历史

- 自动记录复制过的文字和图片，数据保存在本机。
- 支持搜索并快速找回以前复制过的内容。
- 使用较早的历史记录后，该记录会自动移动到列表顶部。
- 可选择自动粘贴，将内容直接粘贴回之前正在使用的应用。
- 可配置剪贴板历史的最大保存数量。

### 截图

- 支持区域截图、应用窗口截图和全屏截图。
- 选区保持正常亮度，选区外降低亮度，便于确认截图范围。
- 截图尚未编辑时，可以移动选区，在其他位置截取相同大小的区域。
- 支持保存为 PNG，或直接复制到剪贴板。

### 截图标注

- 支持方框、圆框、线段、箭头和任意涂鸦。
- 支持选择颜色和细、中、粗三种线宽。
- 支持标准字号、多行输入以及再次编辑已有文字。
- 支持高亮、马赛克、水印和二维码识别。
- 鼠标靠近已有标注后，可以选中、拖动、继续编辑或按退格键删除。
- 支持将截图固定在其他窗口上方，方便对照查看。

### OCR 与翻译

- 使用 Apple Vision 提取截图中的文字。
- OCR 结果在独立窗口中展示，可以编辑、局部选择和复制全部内容。
- 使用 macOS 自带的翻译能力翻译图片文字。
- 支持从语言菜单中选择目标语言。
- OCR 和翻译都不需要配置大模型或 API Key。

### 录屏

- 支持录制选中区域或全屏，并导出为 MP4。
- 可选择录制麦克风声音，首次开启时会申请麦克风权限。
- 录制控制条支持暂停、继续和结束录制。
- 录制完成后可以预览、播放、暂停和拖动进度条。
- 支持下载 MP4，或复制到剪贴板。

### 快捷键与语言

- 可以自定义截图工具和剪贴板历史的全局快捷键。
- 快捷键与其他应用冲突时，仍然可以从菜单栏打开对应功能。
- 支持简体中文和英文界面。
- 默认跟随 macOS：中文系统使用简体中文，其他系统使用英文。

## 隐私说明

Wetools 尽可能使用 macOS 本地能力完成工作：

- 剪贴板历史只保存在本机。
- OCR 使用 Apple Vision。
- 翻译使用 macOS 自带的翻译能力。
- 不需要配置大模型或第三方 API Key。
- Wetools 不会主动上传截图、录屏或识别出的文字内容。

## 系统要求

- Apple Silicon Mac
- macOS 13 或更高版本
- 建议使用 macOS 14 或更高版本，以获得完整的截图体验
- 截图和录屏需要“屏幕录制”权限
- 自动粘贴和模拟输入需要“辅助功能”权限

可以在 **系统设置 > 隐私与安全性** 中管理权限。修改屏幕录制权限后，请完全退出并重新打开 Wetools。

## 安装

1. 从 [GitHub Releases](https://github.com/jiangbo9510/wetools/releases/latest) 下载最新 DMG。
2. 打开 DMG，将 Wetools 拖入“应用程序”文件夹。
3. 启动 Wetools，并根据提示授予 macOS 权限。

当前公开版本使用临时签名，尚未经过 Apple Developer ID 公证。首次启动时，可能需要在 **系统设置 > 隐私与安全性** 中确认允许打开。

## 使用方式

Wetools 启动后常驻在 macOS 菜单栏。

1. 从菜单栏或全局快捷键打开截图工具。
2. 选择截图、全屏截图、录屏或提取文字。
3. 拖拽选择范围，或者将指针放在应用窗口上并点击。
4. 使用浮动工具栏进行标注、保存、复制、固定截图、文字识别或开始录屏。

从菜单栏或快捷键打开剪贴板历史，搜索需要的记录，然后按下回车或点击记录，即可恢复并粘贴内容。

## 当前限制

- 长截图仍在开发中，目前已暂时隐藏入口。
- 录屏仅导出 MP4，不支持 GIF 录制。
- 首次开启麦克风录制时，需要授予麦克风权限。
- 公开构建尚未使用 Apple Developer ID 签名和公证。

## 从源码运行

使用 Xcode 打开 `Wetools.xcodeproj`，在 Apple Silicon Mac 上运行 `Wetools` Scheme。

常用命令：

```sh
make run
make test
make release-local
```
